# Faizan Memon Portfolio

A responsive, single-page portfolio for Faizan Memon and his client-facing work at Pelquant.

## Deploy on Vercel

This is a static HTML site. Import the repository into Vercel and use:

- Framework preset: Other
- Build command: leave empty
- Output directory: `.`
- Install command: leave empty

Vercel serves `index.html` from the repository root. The production URL is `https://faizan-memon-portfolio.vercel.app/`; `robots.txt` and `sitemap.xml` are configured for it.
